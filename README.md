# Social Media Engagement Analysis:
###  Project Description:
    This project analyzes social media engagement data to uncover user behavior, platform performance, platform trends, and user engagement patterns. The dataset was cleaned and transformed using SQL, followed by interactive dashboard creation using with Power BI to generate actionable business insights.
###  Project Objectives:
    Analyze user engagement across different social media platforms.Identify the most active platform and top-performing content. Measure engagement metrics such as likes, comments, shares, and impressions. find the peak user activity hours and optimal posting times.Analyze sentiment and emotion distribution across posts.
### Tools & Technologies:
    1. SQL (Data Cleaning & Analysis)
    2.  Power BI (Dashboard & Visualization)
    3.  Excel (Data Source)
    4. DAX (Measures & KPIs)
###  Business Analysis Performed:
    1. Data Cleaning and Validation
    2. Duplicate Removal
    3. Missing Value Analysis
    4.Platform-wise Engagement Analysis
    5.Likes vs Comments Correlation Analysis
    6.Emotion Type Distribution Analysis
    7.Day of Week vs Impressions Analysis
    8.User Activity by Hour Analysis
    9.Most Active Platform Analysis
    10. Engagement Rate Analysis
